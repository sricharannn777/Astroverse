# ASTROVERSE — Mission Design & Educational Curriculum

## 1. Curriculum Overview

The ASTROVERSE mission structure provides an authentic, progressive curriculum based on the core engineering disciplines of lunar colonization. Each mission pairs an in-game physical interaction with genuine NASA scientific research.

```
+----------------------------------------------------------------------------------+
| MISSION 1: Solar Power       -->  Photovoltaic energy harvesting on the Moon     |
| MISSION 2: Life Support      -->  ECLSS closed-loop oxygen & atmospheric systems |
| MISSION 3: Radiation Shield  -->  In-situ regolith shielding vs. cosmic rays     |
| MISSION 4: Space Botany      -->  Hydroponic agriculture & LED plant photobiology|
| MISSION 5: Space Weather     -->  Solar flare monitoring & storm alert protocols |
+----------------------------------------------------------------------------------+
```

## 3. Distinction of Data & Implementation Fidelity

To ensure absolute academic integrity and transparency, ASTROVERSE clearly classifies the realism of every game component:

| Feature / System | Realism Classification | Description & Technical Boundary |
| :--- | :---: | :--- |
| **NASA DONKI Solar Flare Feed** | **LIVE / HISTORICAL** | Connected to official NASA CCMC DONKI REST API (`/DONKI-API/get/FLR`). In offline or restricted network modes, delivers authentic verified historical observation data from NOAA `GOES-16 SUVI` (Sunspot AR3664). |
| **Lunar Surface Gravity** | **PHYSICAL ENGINE** | Calibrated to `32.4 studs/s²`, exactly 1/6th of standard Earth gravity (`196.2 studs/s²`). Astronaut jump trajectory and rover airtime obey low-gravity parabolic equations. |
| **Lunar Downforce & Gyro Leveling** | **SIMULATED** | Uses synthetic `VectorForce` and proportional leveling algorithms to improve game feel and prevent vehicle flipping on blocky video game terrain. |
| **Outpost Modules & Habitat Layout** | **EDUCATIONAL MOCKUP** | Inspired by NASA Artemis Base Camp concept designs. Compressed in spatial scale to maintain rapid, engaging gameplay for 7–12 year old players. |
| **Apollo 11 & Tiranga Memorials** | **HISTORICAL TRIBUTE** | Recreated in commemorative scale featuring authentic historic plaques, flags, and educational memorial markers. |
